Built for Swedish Medical Evaluation

SMLB measures how language models handle Swedish medical terminology, clinical reasoning, exam-style questions, emergency scenarios, and general medicine cases. It is designed for transparent model comparison, research, and medical education experiments.

What The Paper Figures Show

The figures show that SMLB is not just a leaderboard. Strong models do well overall, but the sub-benchmarks expose different behaviors: emergency reasoning, broad Swedish medical exam knowledge, literature comprehension, answer-label bias, and format reliability.

GRPO / RLVR Dataset

The repository includes a compact native Swedish GRPO dataset for reward-verifiable medical multiple-choice experiments. It includes deterministic reward code, a local Mac smoke check, and a CUDA training script for TRL.

Use this benchmark for evaluation, research, and medical education experiments. Do not treat it as a clinical decision system.

How Can I Contribute?

SMLB improves when contributions make the benchmark more clinically meaningful, transparent, and reproducible. The most useful work is often careful: reviewing medical correctness, documenting provenance, adding clean evaluations, and making the tooling easier to run.

Clinicians

Review questions and answers, flag ambiguity, add Swedish clinical practice notes, and identify unsafe assumptions.

Researchers

Run new model evaluations, analyze error patterns, compare prompting strategies, and report confidence intervals.

Developers

Improve loaders, parsing, reproducibility, documentation, CI checks, and local evaluation workflows.

LLM / RL Contributors

Extend the GRPO/RLVR dataset, strengthen reward checks, test small-model recipes, and document failure cases.

New data should include source provenance, licensing, answer keys, and a clear task format. New results should include model version, prompt, decoding settings, and the evaluation script used.
